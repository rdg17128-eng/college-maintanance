# CampusCare Client Frontend

Frontend user interface for the College Maintenance Management System built using **HTML5**, **CSS3**, **JavaScript**, and **React.js**.

## Overview

- **HTML & CSS**: Semantic page structure, responsive layouts, and modern styled components.
- **React.js**: Reusable components, state management for user authentication, and complaint ticket interactions.
- **Portals**:
  - Student Portal
  - Faculty Portal
  - Admin Dashboard
